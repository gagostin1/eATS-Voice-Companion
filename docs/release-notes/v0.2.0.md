# eATS Voice Companion v0.2.0 — Public Beta

This is the first full public-beta release of eATS Voice Companion. It turns spoken controller phraseology into eATS radio-command tokens, stages the result in the lower-left radio field, and always leaves the final Enter key to the controller.

## Highlights

- Modern three-tab interface focused on push-to-talk operation
- Configurable non-exclusive global PTT hotkey that can be shared with TeamSpeak
- Higher-accuracy local Whisper `small.en` transcription with scenario-aware prompting
- Active airline and general-aviation N-number callsign recovery
- Assigned-STAR and aircraft-route context for descend-via, direct, crossing, and published-speed instructions
- Ranked best-effort command selection for every non-empty recording with active-aircraft context
- Automatic stage-only entry that clears and targets the lower-left eATS radio field
- Combined commands, altimeters, headings, altitudes, speeds, Mach, approaches, transponder commands, frequency changes, crossing restrictions, and more
- Self-contained Windows x64 package; no separate .NET runtime installation required

## Installation

1. Download `EatsVoiceCompanion-win-x64.zip` below.
2. Optionally verify its SHA-256 checksum at the bottom of these notes.
3. Extract the entire ZIP to a folder.
4. Start `EatsVoiceCompanion.App.exe`.
5. Configure the microphone, eATS data directory, controller position, and PTT hotkey under **Settings**.

The first transcription downloads and verifies the local Whisper model. Internet access is only required for that initial model download.

## Important operating note

Best-effort recognition can be wrong. Always inspect the command staged in eATS before pressing Enter. The companion never presses the final Enter key automatically.

## Requirements

- Windows 10 or Windows 11, 64-bit
- eATS installed separately
- Microsoft Visual C++ Redistributable for Visual Studio 2022 (x64)
- AVX, AVX2, FMA, and F16C CPU support
- A Windows-compatible microphone
