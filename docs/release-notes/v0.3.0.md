# eATS Voice Companion v0.3.0 — Adaptive Recognition Beta

This release makes voice operation substantially more reliable, easier to set
up, and more practical to keep visible during an eATS session. It also adds an
opt-in correction pipeline so real recognition failures can improve later
releases.

## Highlights

- First-run microphone, push-to-talk, and ten-phrase Atlanta voice calibration
- Local correction memory that teaches Whisper prompts and route-safe fix aliases
- Immediate **Looks right** and **Fix this** feedback plus correction history
- Context-aware recovery using active callsigns, STARs, flight plans, and fixes
- Live audio-quality warnings without blocking best-effort recognition
- Compact always-on-top controller mode and system-tray operation
- Automatic sanitized correction contributions when participation is enabled
- Local outbox retries, sent receipts, JSON inspection, deletion, and export
- Automatic command-field clearing before staging, with final Enter still manual

## Privacy and contribution behavior

Speech recognition and correction learning remain local. When recognition
improvement is enabled, saving a correction sends a sanitized text-only report
to the project endpoint. Reports can include transcripts, generated and expected
commands, app version, callsign, controller position, and limited STAR or route
context. Microphone audio, Windows usernames, local paths, and complete eATS
files are not included.

Participation is enabled by default in the clearly presented consent notice and
can be disabled at any time under **Settings > Development feedback**. Existing
users must acknowledge the updated automatic-send behavior before previously
queued reports are submitted.

## Installation

1. Download and run `EatsVoiceCompanion-Setup-win-x64.exe` below. It installs for the current Windows user and does not require administrator access.
2. Optionally verify its SHA-256 checksum at the bottom of these notes.
3. Complete voice setup, then configure and detect the eATS data directory.

The portable `EatsVoiceCompanion-win-x64.zip` remains available for users who prefer a no-install copy. Extract the entire ZIP before running `EatsVoiceCompanion.App.exe`.

The package is self-contained and does not require a separate .NET installation.
The first transcription downloads and verifies the local Whisper model.

The installer is not yet code-signed, so Windows SmartScreen may display an
unknown-publisher warning. Compare the downloaded file's SHA-256 value with the
checksum appended to these release notes before running it.

## Important operating note

Best-effort recognition can be wrong. Always inspect the command staged in eATS
before pressing Enter. The companion never presses the final Enter key.

## Requirements

- Windows 11, 64-bit
- eATS installed separately
- Microsoft Visual C++ Redistributable for Visual Studio 2022 (x64)
- AVX, AVX2, FMA, and F16C CPU support
- A Windows-compatible microphone
