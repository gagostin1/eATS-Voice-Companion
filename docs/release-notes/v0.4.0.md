# eATS Voice Companion v0.4.0 — Faster Voice Control

This release makes the voice workflow substantially faster and allows decoded voice commands to be submitted directly in eATS.

## Highlights

- Whisper now warms in the background and remains loaded for the application session. Repeated transmissions no longer reload the roughly 488 MB model from disk.
- Voice commands now press the final Enter key automatically by default after the command has been entered and eATS focus has been rechecked.
- Automatic Enter can be disabled in **Settings** for controllers who prefer to review each staged command manually.
- Commands created on the **Generate Command** tab remain stage-only and always require manual review and submission.
- The app checks that eATS is still in the foreground immediately before submitting. Typing or focus failures prevent the final Enter from being sent.
- New structured timing logs separate model acquisition, context generation, Whisper decoding, command readiness, and eATS input time.
- The app checks GitHub for new releases once per day and shows a non-blocking update banner. Opening and installing an update remains user initiated.

## Important behavior change

Automatic Enter applies to best-effort voice results as well as strictly interpreted results. Best-effort recognition can be wrong. To retain the previous stage-and-review workflow, clear **Press Enter automatically for voice commands** in Settings and save the settings.

If the app reports an input or submission error, inspect eATS before retrying because the command may have been partially entered or submitted.

## Install or upgrade

Run `EatsVoiceCompanion-Setup-win-x64.exe` to install or upgrade in place. The portable ZIP remains available for users who do not want an installer. Both packages are self-contained and do not require a separate .NET installation.

The installer is not yet code-signed, so Windows SmartScreen may display an unknown-publisher warning. Package SHA-256 checksums are appended to these notes automatically by the release workflow.
